## Catatan hak cipta

Clean Code adalah karya berhak cipta. Skill ini tidak menggantikan buku.
Ringkasan bab adalah sintesis orisinal untuk penerapan internal. Untuk
detail, contoh kode, dan argumen lengkap, baca buku resmi atau halaman
O'Reilly yang berlisensi.
